## 分四個 PR，每個獨立審查

### PR A：核心重做
- 新增 `WindowTracker`：AX 觀察者加快取，按下快捷鍵時直接取快取，不再同步掃描全部 App（現有 WIP 每次最多等每個 App 0.1 秒）。
- 快捷鍵模型改成可設定、可多組（資料模型一開始就支援多組，PR C 才開放到 9 組）。
- 縮圖磚塊 UI：ScreenCaptureKit 擷取；沒有螢幕錄製權限時退回 App 圖示加標題，不阻擋使用。
- 方向鍵、vim 鍵、滑鼠 hover 選取。
- 視窗操作：關閉、最小化、全螢幕、隱藏、結束 App。
- 沿用 WIP 的 `InputTap`、`OverlayPanel`、Dock hover 偵測與純邏輯測試；順手修 Dock 自動隱藏時面板位置偏低，並關掉 `dockDebug` 預設值。

### PR B：篩選、排序、分組、例外清單
- 篩選：目前畫面、隱藏與最小化的視窗、全螢幕視窗。
- 排序：最近使用、最近建立、App 名稱字母。
- 分組 App、分組分頁。
- 例外清單：依 Bundle ID 排除。
- 設定頁新增「視窗切換」分頁。
- **Space 原型**：用 CGS／SkyLight 列出所有 Space 的視窗並依 Space 篩選。先做獨立的小原型，在本機驗證可行與穩定度再決定是否正式納入；失敗或 API 失效時降級為只看目前 Space。

### PR C：Pro 對照功能
- 外觀樣式：Thumbnails、App Icons、Titles。
- Auto Size：依視窗數量與畫面大小計算磚塊尺寸。
- Search：切換器開著時打字過濾，標題與 App 名稱模糊比對並高亮；放開快捷鍵後進入搜尋為另一種放開行為。
- 多組快捷鍵（上限 9）：各自的篩選、排序、放開行為與外觀覆寫；衝突偵測擋掉系統保留組合。

### PR D：周邊
- 多螢幕：切換器顯示在滑鼠所在、使用中視窗所在或主畫面。
- 外觀：深淺色跟隨系統、淡入淡出動畫、出現延遲。
- 設定匯入匯出（JSON，匯入時驗證欄位型別與範圍）。
- 繁中與英文介面、README 更新、單元測試補齊。

### 不做
- **觸控板手勢**：需要私有 MultitouchSupport，穩定性最差，決定不做。

## 風險

- **私有 API**：視窗與 Space 資訊需要 `_AXUIElementGetWindow` 與 CGS／SkyLight。本專案不上 App Store，可以用，但每次 macOS 大版本要重測，並在 API 失效時優雅降級。
- **主執行緒卡住**：AX 呼叫可能被別的 App 拖住。AX 讀取放背景佇列，只有 UI 更新回主執行緒；事件攔截維持 `InputTap` 的獨立執行緒設計。
- **權限**：輔助使用必要；螢幕錄製可選。本機簽章必須沿用穩定的開發憑證，否則每次重建都要重新授權。
- **與系統 Cmd+Tab 衝突**：只在使用者開啟開關時攔截，關閉時完全不攔截；異常時事件攔截要能自動停用而不是吃掉按鍵。
- **效能**：縮圖擷取限制頻率與尺寸，視窗很多時用延遲載入；目標是按下快捷鍵到顯示在 100 ms 內。
- **資安**：視窗標題可能含敏感內容，不寫入日誌、不上傳；匯入設定視為外部輸入並驗證。
