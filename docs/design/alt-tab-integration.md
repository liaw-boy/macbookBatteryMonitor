## 分階段，每階段一個獨立 PR

### 階段 0：處理現有 WIP
- WIP 在 `feature/dock-window-switcher`，未提交。**不丟棄**：先提交到該分支保存，再決定哪些沿用。
- 可沿用的底層：`InputTap`（獨立執行緒的事件攔截）、`OverlayPanel`、Dock 圖示 hover 偵測、`DockWindowList` 的視窗過濾與測試。
- 要換掉的：`WindowSwitcher` 的文字清單 UI 與 `SwitcherModel`，改為階段 1 的新設計。
- 順手修完 Dock 自動隱藏時面板位置偏低的問題，並關掉 `dockDebug` 預設值。

### 階段 1：核心切換器
- 視窗追蹤：用輔助使用（AX）觀察視窗建立、關閉、標題、最小化，維護「最近使用順序」，不輪詢。
- 縮圖：ScreenCaptureKit 擷取，沒有螢幕錄製權限時退回 App 圖示加標題，不阻擋使用。
- 磚塊格狀版面、選取高亮、Tab／Shift+Tab／方向鍵／vim 鍵／滑鼠 hover。
- 視窗操作快捷鍵：關閉、最小化、全螢幕、隱藏、結束 App。
- 快速按一下直接回到上一個視窗，不顯示切換器（沿用 WIP 行為）。
- 先做單一快捷鍵（預設 Cmd+Tab 取代），但資料模型直接支援多組，避免階段 3 重寫。

### 階段 2：篩選、排序、分組
- 篩選：所有／目前畫面／目前 Space、隱藏與最小化的視窗、全螢幕視窗。
- 排序：最近使用、最近建立、App 名稱字母。
- 分組 App、分組分頁（原生分頁視窗當一個）。
- 例外清單：依 Bundle ID 排除，可從執行中 App 或磁碟加入。

### 階段 3：Pro 對照功能
- 外觀樣式：Thumbnails（階段 1）、App Icons（只顯示圖示）、Titles（精簡清單）。
- Auto Size：依視窗數量與畫面大小計算磚塊尺寸，下限與上限可設。
- Search：切換器開著時打字過濾，標題與 App 名稱模糊比對、高亮相符字元；「放開快捷鍵後進入搜尋」為另一種放開行為。
- 多組快捷鍵（上限 9）：每組有自己的篩選、排序、放開行為與外觀覆寫，衝突偵測要擋掉系統保留組合（例如強制結束）。

### 階段 4：周邊
- 多螢幕：切換器顯示在滑鼠所在、使用中視窗所在或主畫面。
- 外觀：深淺色跟隨系統、淡入淡出動畫、出現延遲（避免快速切換時閃爍）。
- 設定匯入匯出（JSON，匯入時驗證欄位型別與範圍）。
- 觸控板手勢：需要私有 MultitouchSupport，**預設不做**，等前面階段穩定後再評估。

### 階段 5：收尾
- 繁中與英文介面、README 與 README.en 更新、單元測試補齊、設定頁新增獨立的「視窗切換」分頁。

## 風險

- **私有 API**：視窗與 Space 資訊需要 `_AXUIElementGetWindow` 與 CGS／SkyLight。本專案不上 App Store，可以用，但每次 macOS 大版本要重測，並在 API 失效時優雅降級。
- **主執行緒卡住**：AX 呼叫可能被別的 App 拖住。AX 讀取放背景佇列，只有 UI 更新回主執行緒；事件攔截維持 `InputTap` 的獨立執行緒設計。
- **權限**：輔助使用必要；螢幕錄製可選。本機簽章必須沿用穩定的開發憑證，否則每次重建都要重新授權。
- **與系統 Cmd+Tab 衝突**：只在使用者開啟開關時攔截，關閉時完全不攔截；異常時事件攔截要能自動停用而不是吃掉按鍵。
- **效能**：縮圖擷取限制頻率與尺寸，視窗很多時用延遲載入；目標是按下快捷鍵到顯示在 100 ms 內。
- **資安**：視窗標題可能含敏感內容，不寫入日誌、不上傳；匯入設定視為外部輸入並驗證。
